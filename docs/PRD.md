# PRD: FreeSign

## 목표
프리랜서 개인이 **"계약 → 서명 → 청구 → 입금 → 세금 정리"를 하나의 데이터 흐름**으로 관리하고, 대시보드로 "내 돈이 어디까지 왔는지"를 한눈에 보는 한국형 올인원 도구. 방어 가능한 코어는 **"계약 → 지급기한 → 입금/미수 증빙"의 기록 체인**.

## 사용자
**프리랜서 개인** (B2C). 예: 인스타·링크드인·유튜브 등 여러 채널로 의뢰를 받고, 한 달에 클라이언트 3~4명을 상대하며, 지금은 계약을 카톡·메일로 합의하고 정산을 엑셀에 손으로 적는 디자이너·개발자·마케터 등.

겪는 통증: **정산 누락·중복 청구**("이 사람 입금했던가?"), **범위 혼동**("범위가 어디까지였지?"), **세금 정리 부담**("5월에 뭘 얼마 받았는지 다 뒤져야 해").

> B2B(회사가 외주자를 관리)는 범위 제외. v1은 **순수 1인용** — 클라이언트는 접속하지 않는다.

## 핵심 기능
1. **정산 기록 체인** — 클라이언트(계약 경로 태깅) → 계약 → 인보이스(원천징수 자동 계산) → 정산 상태 토글 → 대시보드(미수금·이달 수익·임박/지연·채널 수익 TOP). 모든 상태 전이는 append-only 이벤트 로그에 기록되어 상세 화면에 이력 타임라인으로 노출된다.
2. **AI 계약서 초안** — 범용 용역계약서 골격(코드 소유)에 Claude가 (a) 사용자의 대충 쓴 범위를 정식 조항 문구로 다듬고, (b) 조항별 평문 요약을 붙이고, (c) 필수조항 누락 시 `[검토 필요]` 플래그. 생성 → 자유 편집 → 확정. 항상 "초안·법적 자문 아님" 면책 노출.
3. **간이 서명 + PDF + 세금 내보내기** — 프리랜서 본인 캔버스 서명(감사로그 + 문서 해시)으로 증빙 기록, 계약서·인보이스 PDF(한글 임베드), `/reports`에서 채널별 수익 리포트 + 연도별 CSV 내보내기(종소세 정리).

## MVP 제외 사항
- **클라이언트 접속·공유 링크·맞서명** — v1은 프리랜서 본인 서명만. 링크 맞서명은 v2.
- **실 결제(PG) 연동** — 정산은 계좌이체 + 수동 상태 토글. 실 PG(웹훅·리다이렉트)는 v2에서 `PaymentProvider` 뒤로 교체.
- **법적효력 전자서명** — 간이 서명으로 원리만 재현(예시적 무결성). 실서명 API는 v2에서 `SignatureProvider` 뒤로 교체.
- **세무 신고 대행·세액 확정** — 원천징수는 "참고용 계산·기록·내보내기"까지만(세무사법 준수).
- **이메일 리마인더 발송** — 인앱 대시보드 하이라이트만. 이메일은 v2.
- **별도 프로젝트 엔티티** — 계약 1 : 인보이스 N으로 충분.
- **다중 통화** — v1은 KRW 고정(currency 컬럼 없음).
- **AI 템플릿 다종** — 범용 용역계약서 1종.

## 디자인
- **라이트 테마 + 블루 포인트 1색.** 중립 배경(흰/그레이) 위에 브랜드 블루 1색을 포인트로. 마케팅 페이지가 아니라 매일 쓰는 대시보드 도구처럼 보여야 한다.
- **정산 상태는 시맨틱 신호색** — 완료(green) / 대기·임박(amber) / 미수·지연(red).
- **AI 슬롭 금지** — glass morphism, gradient text, 보라/인디고 브랜드색, 배경 gradient orb 등 금지(상세: `UI_GUIDE.md`).
- **면책 노출** — AI 계약서·원천징수 계산은 화면·PDF·확정 직전에 "초안·참고용·전문가 검토 권장" 면책을 반복 노출.
