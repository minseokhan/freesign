# PRD: 매듭 (Maedeup)

## 목표
프리랜서 개인이 **"계약 → 서명 → 청구 → 입금 → 세금 정리"를 하나의 데이터 흐름**으로 관리하고, 대시보드로 "내 돈이 어디까지 왔는지"를 한눈에 보는 한국형 올인원 도구. 방어 가능한 코어는 **"계약 → 지급기한 → 입금/미수 증빙"의 기록 체인**.

## 사용자
**프리랜서 개인** (B2C). 예: 인스타·링크드인·유튜브 등 여러 채널로 의뢰를 받고, 한 달에 클라이언트 3~4명을 상대하며, 지금은 계약을 카톡·메일로 합의하고 정산을 엑셀에 손으로 적는 디자이너·개발자·마케터 등.

겪는 통증: **정산 누락·중복 청구**("이 사람 입금했던가?"), **범위 혼동**("범위가 어디까지였지?"), **세금 정리 부담**("5월에 뭘 얼마 받았는지 다 뒤져야 해").

> B2B(회사가 외주자를 관리)는 범위 제외. **계정은 프리랜서 1인용** — 클라이언트는 계정을 만들지 않고, 서명 링크(`/sign/[token]`)를 통해 계약 열람·서명만 한다.

## 핵심 기능
1. **정산 기록 체인** — 클라이언트(계약 경로 태깅) → 계약 → 인보이스(원천징수 자동 계산) → 정산 상태 토글 → 대시보드(미수금·이달 수익·이번 달 예정 입금·계약 파이프라인 단계별 건수·임박/지연·채널 수익 TOP). 모든 상태 전이는 append-only 이벤트 로그에 기록되어 상세 화면에 이력 타임라인으로 노출된다.
2. **AI 계약서 초안 + 기존 계약 불러오기** — 범용 용역계약서 골격(코드 소유)에 Claude가 (a) 사용자의 대충 쓴 범위를 정식 조항 문구로 다듬고, (b) 조항별 평문 요약을 붙이고, (c) 필수조항 누락 시 `[검토 필요]` 플래그. 생성 → 자유 편집 → 확정. 발주처가 보낸 PDF도 업로드할 수 있으며, Claude가 10개 표준 조항·금액·기간·제목을 추출하면 사용자가 검토·수정한 뒤 저장한다. 이 경우 업로드한 원본 PDF 자체가 증빙이므로 별도 캔버스 서명 없이 곧바로 **성사(signed)** 상태로 저장하고, 문서 해시는 원본 PDF 바이트로 산출한다. 금액·기간 등 방어 코어 값은 무검증 저장하지 않고, AI 실패 시 수기 입력 가능한 폴백으로 이어진다. 항상 "초안·법적 자문 아님" 면책 노출.
3. **쌍방 전자서명 + PDF + 세금 내보내기** — 프리랜서가 캔버스 서명과 함께 상대방에게 서명 링크를 보내면, 비로그인 상대방이 열람·서명해 계약이 완결된다(발송 시점 해시 동결 + 감사추적 + RFC 3161 타임스탬프 + 완결증명서). 계약서·인보이스·증명서 PDF(한글 임베드), `/reports`에서 채널별 수익 리포트 + 연도별 CSV 내보내기(종소세 정리). 입증력은 "효력 있음/없음"이 아니라 단계로 표기한다(`record` 단독 기록 / `mutual` 맞서명, `docs/LEGAL_SIGNATURE.md`).
4. **청구·수금 자동화(Pro)** — 매달 가치가 발생하는 자동화 묶음. 연체 인보이스의 독촉 메일 초안 자동 작성, 반복(구독형) 인보이스 초안 자동 생성, 과거 계약의 조항 약점을 짚는 AI 인사이트. **자동화는 초안까지만** — 클라이언트에게 나가는 메일·인보이스 발행은 항상 소유자가 검토·승인한 뒤에 일어난다.

## 요금제 (Free / Pro)
월 구독(Polar). 무료의 방어 가능한 코어(기록 체인)는 온전히 열어 락인하고, **매달 가치가 발생하는 자동화·인사이트**와 상한 해제만 과금한다. 상세 경계·게이팅 방식은 ADR-010(갱신)·ADR-011, 사용자에게 보이는 목록은 `src/components/billing/plan-comparison.tsx`가 정본.

- **Free** — 클라이언트·인보이스 무제한, 새 계약 작성 1건·서명 요청 발송 1건(activation 체험), 기존 계약 불러오기(AI 파싱) 누적 5회, 미수금·이달 수익 대시보드, 계약서·인보이스 PDF.
- **Pro** — 계약 작성·서명·불러오기 무제한 + 반복 인보이스 자동 초안 + 미수금 독촉 메일 초안 + AI 계약 인사이트 + 채널·클라이언트 수익 랭킹 + 세금 신고용 CSV.
- **다운그레이드해도 데이터는 지우지 않는다** — 자동화와 고급 뷰만 잠근다.

## MVP 제외 사항
> 아래는 v1 출시 시점의 제외 항목이다. 취소선 항목은 이후 실제로 구현됐다.

- ~~**클라이언트 접속·공유 링크·맞서명**~~ — v2에서 자체 구현(토큰 링크 + 비로그인 서명, ADR-009).
- ~~**이메일 리마인더 발송**~~ — Resend 연동. 단 클라이언트 발송은 항상 소유자 승인 뒤에만(ADR-011).
- **실 결제(PG) 연동** — 인보이스 정산은 여전히 계좌이체 + 수동 상태 토글. Polar는 *구독 결제* 전용이며, 인보이스 수금 PG는 계속 `PaymentProvider` 뒤의 v2 과제.
- **법적효력 전자서명(공인 인증)** — 이메일 소유확인 + 해시 동결 + TSA로 입증력을 재현하는 수준. 본인인증 승급·국내 공인 TSA는 확장 지점만 확보.
- **세무 신고 대행·세액 확정** — 원천징수는 "참고용 계산·기록·내보내기"까지만(세무사법 준수).
- **완전 자동 발송** — 크론은 초안까지만. 대외 커뮤니케이션의 최종 결정권은 사람에게 남긴다.
- **별도 프로젝트 엔티티** — 계약 1 : 인보이스 N으로 충분.
- **다중 통화** — KRW 고정(currency 컬럼 없음).
- **AI 템플릿 다종** — 범용 용역계약서 1종.

## 디자인
- **라이트 테마 + 남색 포인트 1색.** 중립 배경(흰/그레이) 위에 브랜드 남색 1색을 포인트로. 마케팅 페이지가 아니라 매일 쓰는 대시보드 도구처럼 보여야 한다.
- **정산 상태는 시맨틱 신호색** — 완료(green) / 대기·임박(amber) / 미수·지연(red).
- **AI 슬롭 금지** — glass morphism, gradient text, 보라/인디고 브랜드색, 배경 gradient orb 등 금지(상세: `UI_GUIDE.md`).
- **면책 노출** — AI 계약서·원천징수 계산은 화면·PDF·확정 직전에 "초안·참고용·전문가 검토 권장" 면책을 반복 노출.
